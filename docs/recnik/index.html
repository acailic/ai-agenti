REČNIK — srpsko-engleski rečnik pojmova

Kako kurs piše i govori o agentima: srpski termin, sa engleskim originalom u zagradi. Referenca za sve module.

U ovom kursu važi dogovor: svaki termin pri prvoj upotrebi u tekstu dobija engleski original u zagradi — npr. alat (eng. tool) — jer ćete u dokumentaciji, porukama o greškama i na poslu na ta ista imena naići na engleskom. Ovaj rečnik ih skuplja na jednom mestu: srpsko ime, engleski original, kratko značenje i modul u kome se pojavljuje.

Dogovor o prevodima je pragmatičan: nekima je srpski termin potpuno ravnopravan (token, kontekst, temperatura), neki ostaju pretežno na engleskom jer su se u praksi udomaćili (tool use, RAG, LLM-as-a-judge). U nedoumici: pišemo srpski, engleski u zagradi — i nikad mešamo ćirilicu i latinicu (kurs je na latinici i ekavici).

1. Osnove: model i razgovor

Termin Na engleskom Značenje Modul
veliki jezički model large language model (LLM) Model obučen na ogromnom tekstu; iz konteksta predviđa sledeći token. „Motor" agenta. 00
token token Jedinica teksta koju model obrađuje (približno pola do tri četvrtine reči za engleski). Od tokena zavise cena, brzina i ograničenja. 01
kontekst context Sve što model vidi u jednom pozivu: sistemski tekst, istorija, rezultati alata, dokumenti. 01
kontekstni prozor context window Maksimalan broj tokena koji staje u jedan poziv; konačan je, meri se u desetinama ili stotinama hiljada. 01
prompt prompt Ulazni tekst za model. U ovom kursu: program koji se verzionisa i meri, ne poruka prijatelju. 01
sistemski prompt system prompt Poruka uloge system: identitet, pravila, format i ograničenja — „konfiguracioni fajl" za model. 01
temperatura temperature Parametar koji kontroliše raznovrsnost izlaza: niska → ponovljivo, visoka → kreativno. Za agente: niska. 01
halucinacija hallucination Samouvereno izmišljanje kada model nema podatak; svojstvo načina rada, ne bug — zaobilazi se dizajnom (alati, izvori, testovi). 01
API API Programski interfejs preko koga kod razgovara sa modelom; poziv = lista poruka, odgovor = izlaz modela. 01
API ključ API key Tajni niz koji potvrđuje vaš nalog; kao lozinka — živi u environment varijabli, nikad u kodu. 01
environment varijabla environment variable Podešavanje procesa izvan koda (npr. Z_AI_API_KEY); standardno mesto za tajne. 01
OpenAI-kompatibilan interfejs OpenAI-compatible interface Dogovor o obliku poziva koji su prihvatili mnogi provajderi; promenom base_url isti kod radi sa drugim modelima. 01

2. Alati

Termin Na engleskom Značenje Modul
alat tool Funkcija u vašem kodu koju model može da zatraži; jedina veza modela sa svetom podataka i akcija. 02
korišćenje alata tool use, function calling Sposobnost modela da umesto teksta vrati zahtev za izvršenje funkcije sa argumentima. 02
definicija alata tool definition Ono što model vidi: ime, opis i šema parametara. Opis je interfejs ka modelu — piše se kao dokumentacija. 02
šema parametara JSON Schema Formalni opis koje parametre alat prima, kojeg tipa i koji su obavezni. 02
poziv alata tool call Zahtev modela: „izvrši funkciju X sa argumentima Y"; argumenti stižu kao JSON tekst. 02
sandbox sandbox Ograđen prostor (npr. jedan direktorijum) unutar koga alat sme da radi; sve izvan — greška. 02
najmanja dozvola least privilege Alat ume samo ono što mu treba za zadatak: čitanje, ne brisanje; jedan folder, ne ceo disk. 02
čovek u petlji human in the loop Potvrda čoveka pre izvršenja osetljive ili nepovratne operacije. 03

3. Agent i petlja

Termin Na engleskom Značenje Modul
agent AI agent Sistem u kome LLM odlučuje i deluje: koristi alate, pravi korake ka cilju, koriguje sebe. 00
petlja agenta agent loop Ciklus: razmišlja → traži akciju → vidi rezultat → ponovo; dok ne završi ili ne stane. 03
opažaj–razmišljaj–deluj perceive–think–act Klasični ciklus agenta: prikupi stanje, odluči, izvrši — pa opet. 03
samo-korekcija self-correction Sposobnost agenta da grešku alata pretoči u novi, ispravljeni pokušaj umesto da stane. 03
trag trace Zapis koraka agenta (alati, argumenti, rezultati, troškovi); čita se i kada je sve prošlo dobro. 03
kočnice step limit, token budget max_koraka, budžet tokena, allow-lista akcija; bez njih agent može da vrti do besvesti. 03
framework agent framework Biblioteka koja slaže petlju, alate i logovanje umesto vas; izbor, ne misterija — ispod je ista petlja. 03

4. Memorija i kontekst

Termin Na engleskom Značenje Modul
memorija memory Sve što agent zna između koraka i između sesija: radna (istorija), sažeta, trajna (baza). 04
radna memorija short-term memory Istorija poruka u kontekstu — ono što agent „zna" tokom tekućeg zadatka. 04
sažeta memorija summarized memory Sažetak starije istorije umesto svih poruka; oslobađa prozor, gubi detalje. 04
trajna memorija long-term memory Sve što agent pamti van kontekstnog prozora (fajlovi, baze, indeks); vraća se po potrebi. 04
model bez stanja stateless Model ne pamti ništa između dva poziva; sve što zna mora biti u kontekstu poziva. 04
povraćaj retrieval Izdvajanje upravo relevantnog sadržaja iz trajne memorije nazad u kontekst. 04
sažimanje summarization Sabijanje starije istorije u kraći tekst da bi se oslobodio kontekstni prozor. 04
ugnežđena reprezentacija embedding Tekst preveden u niz brojeva koji čuva značenje; tekstovi sličnog smisla su blizu jedni drugima. 04
vektorska baza vector database Skladište ugnežđenih reprezentacija sa pretragom po sličnosti. 04
RAG retrieval-augmented generation Obrazac: pronađi relevantne odlomke, ubaci ih u kontekst, pa tek onda generiši odgovor sa izvorom. 04
deljenje na odlomke chunking Sečenje dokumenata na komade pogodne za ugnežđivanje i pretragu; veličina i preklapanje imaju značaja. 04
preklapanje overlap Deo teksta koji se ponavlja između susednih odlomaka, da granica ne preseče činjenicu. 04
pretraga po smislu semantic search Traženje odlomaka po značenju (blizina ugnežđenih reprezentacija), a ne po poklapanju reči. 04
kosinusna sličnost cosine similarity Mera blizine dva vektora (1 = najbliže, 0 = bez veze); osnova pretrage po smislu. 04
k najbližih suseda k-nearest neighbours (k-NN) Povraćaj k vektora najbližih vektoru pitanja. 04
navođenje izvora citation Odgovor uz oznaku odakle je tvrdnja (odlomak, dokument); čini odgovor proverljivim. 04
metapodatak metadata Podaci o podatku: izvor fajla, broj odlomka, datum izmene. 04
izgubljen usred konteksta lost in the middle Relevantan podatak usred dugačkog konteksta se lakše ignoriše. 04
inženjering konteksta context engineering Dizajn onoga što model vidi u svakom koraku: šta ulazi, šta se sažima, šta se pamti van prozora. 05
politika konteksta context policy Pisani dogovor šta ulazi u kontekst: uvek / aktivno / sažeto / van prozora. 05
trovanje kontekstom context poisoning Sadržaj u kontekstu koji pogrešno usmerava modela: protivrečno, zastarelo, ubrizgano. 05
ubrizgavanje uputstava prompt injection Tekst u dokumentu ili rezultatu alata koji glumi naredbu modelu. 05

5. Protokoli i povezivanje

Termin Na engleskom Značenje Modul
protokol protocol Pisani ugovor o obliku poruka između dve strane; N puta M integracija postaje N plus M. 06
protokol konteksta modela Model Context Protocol (MCP) Otvoren standard za povezivanje modela sa spoljnim alatima i izvorima podataka. 06
host host Aplikacija koja pokreće model i odlučuje sa kojim serverima se povezuje. 06
MCP klijent MCP client Deo hosta koji vodi jednu vezu ka jednom serveru; granica na kojoj se proverava i ograničava. 06
MCP server MCP server Program koji nudi alate, resurse i promptove preko protokola — lokalni proces ili udaljeni servis. 06
primitiv primitive Vrsta ponude servera; deli se po tome ko odlučuje: alat (model), resurs (aplikacija), prompt (korisnik). 06
resurs resource Podatak koji server izlaže za čitanje; u kontekst ga ubacuje vaš kod, ne model. 06
JSON-RPC JSON-RPC Format zahteva i odgovora (method, params, id) na kome počiva MCP; notifikacija je poruka bez id i bez odgovora. 06
rukovanje handshake Prvi razgovor veze (initialize): ko je ko, koje verzije i sposobnosti — pre bilo kog posla. 06
otkrivanje alata tool discovery Klijent pita server šta nudi (tools/list) i dobija šeme; menja ručno održavanu listu u kodu. 06
transport transport Kanal kojim putuju poruke: stdio (lokalni proces) ili HTTP (udaljeni servis). 06
imenski prostor namespace Prefiks imena alata imenom servera (recnik.trazi), da se alati dva servera ne sudare. 06
trovanje alatom tool poisoning Opis alata koji glumi uputstvo modelu; tuđi tekst ulazi u kontekst kao vaš. 06
agent-kartica agent card JSON opis agenta za A2A: šta ume (veštine), gde se nalazi, koje sposobnosti podržava. 06
A2A Agent2Agent Protokol za saradnju agenata kao ravnopravnih učesnika: dodeljivanje zadataka, poruke u toku, artefakti. 06

6. Evaluacija

Termin Na engleskom Značenje Modul
evaluacija evaluation Sistematsko merenje koliko je agent dobar; bez nje se radi naslepo. 07
evaluacioni skup evaluation set, test set Verzionisan spisak primera (ulaz → očekivano) na kome se agent meri, uključujući granične slučajeve. 07
scenario scenario Najmanja jedinica evaluacije: id, ulaz, očekivano ponašanje i provere koje padaju glasno. 07
granični slučaj edge case Primer na granici domena: van domena, pogrešna pretpostavka, višedelni zahtev; pola vrednosti skupa. 07
provera check Mali program uz scenario (sadrži / ne sadrži / regex); determinističke provere idu pre sudije. 07
metrika metric Broj koji nešto zaista meri (tačnost, potpunost, trošak po zadatku); bira se po slučaju upotrebe. 07
stopa prolaznosti pass rate Procenat scenarija koji prolaze sve provere; glavni broj, ali nikad jedini. 07
prag threshold Donja granica stope ispod koje je crveno; kao izlazni kod skripte postaje kapija u CI. 07
dif pregled diff review Upareno poređenje ishoda dva pokretanja po scenariju; flipovi objašnjavaju, agregat odlučuje. 07
ocenjivanje pomoću modela LLM-as-a-judge Drugi model ocenjuje odgovore prvog po rubrici; korisno, ali se kalibriše na primerima koje je čovek ocenio. 07
rubrika rubric Pisani kriterijumi po kojima sudija-model sudi; bez nje sudija je izvor nasumičnosti. 07
kalibracija calibration Slaganje sudije sa ljudskim ocenama na par primera, pre nego što mu se poveri skup. 07
pokretač harness Skripta koja spaja skup, agenta i provere: tabela, zapis rezultata, izlazni kod po pragu. 07
regresiona provera regression test Scenario koji je jednom pao i bio popravljen; ostaje zauvek, da greška ne vrati tiho. 07
latencija latency Vreme od zahteva do odgovora; u agentima se sabira iz više koraka. 07

7. Produkcija i multi-agent sistemi

Termin Na engleskom Značenje Modul
višeagentski sistem multi-agent system Više agenata sa podeljenim ulogama, komunikacijom i orkestracijom (ko radi šta i kojim redom); moćno, ali rešenje samo kada jedan agent zaista nije dovolj. 08
orkestracija orchestration Koordinacija više agenata: ko radi šta, kojim redom, ko sudi kad je gotovo; ista petlja kao kod jednog agenta, samo je „alat" sad drugi agent. 08
orkestrator orchestrator Uloga (agent ili običan kod) koja dodeljuje zadatke, sabire rezultate i odlučuje o kraju; u malim sistemima spojena sa planerom. 08
planer planner Uloga koja cilj razlaže na korake plana (potpitanja, podzadatke), obično u strogo definisanom JSON obliku. 08
izvršilac worker, executor Uloga koja radi jedan dodeljeni korak do kraja; ne mora biti model — pretraga je odličan izvršilac. 08
kriticar critic Uloga koja ocenjuje tuđi rezultat po rubrici; mora imati čvrstu granicu popravki, inače se agenti šalju u krug. 08
ugovor (između agenata) contract Dogovoreni oblik poruka između uloga: šta agent prima (zadatak i kontekst), šta vraća (rezultat) i gde su granice. 08
gluvi telefon context degradation Postepeno propadanje sadržaja kroz lanac prenošenja između agenata; lek: artefakt i samo potreban kontekst, ne istorija. 08
razdeli i saberi fan-out/fan-in Orkestracija u kojoj se zadatak podeli na nezavisne delove, oni rade paralelno, pa se rezultati saberu. 08
kvota quota, rate limit Ograničenje broja zahteva ili tokena u jedinici vremena; prekoračenje = greška koju kod mora da obradi. 09
opservabilnost observability Moć da vidite šta agent radi u radu: logovi, tragovi, metrike; produkcija bez nje je crna kutija. 09
potvrda korisnika human-in-the-loop Kapija pred skupim ili nepovratnim akcijama: čovek odobrava, a svaka odluka se upisuje u dnevnik. 09
suvi rad dry run Izvršavanje na papiru: izveštaj „šta bih uradio" bez ijedne promene; najjeftinija odbrana pre opasne akcije. 09
dnevnik odluka audit log Zapis svake odluke o potvrdama (ko, šta, kada, zašto); odgovor na „a ko je to dozvolio?" dolazi iz zapisa, ne iz sećanja. 09
strukturisano beleženje structured logging Svaki događaj je jedna JSON linija sa poznatim poljima; čita ga program (filtriranje, brojanje), ne samo čovek. 09
id traga trace ID Identifikator jednog zadatka koji nose svi njegovi događaji, kroz sve agente; jedan id — svi učesnici — jedan pregled. 09
idempotencija idempotency Svojstvo akcije da izvršena dva puta daje ishod kao jednom; uslov za bezbedan ponovni pokušaj. 09
eksponencijalna zadrška exponential backoff Ponovni pokušaji sa sve dužim čekanjem (1s, 2s, 4s); provajderu se daje vremena da odahne, umesto da ga zaturimo. 09
budžet budget Granica troška po zadatku: meki deo upozorava, tvrdi prekida izuzetkom; budžet bez tvrdog limita je dekoracija. 09
keširanje odgovora response caching Identičan poziv vraća spremljen odgovor bez novog poziva API-ja; štedi na ponovljenim pitanjima. 09
preusmeravanje modela model routing Lakši koraci idu jeftinijem modelu, teški glavnom; smanjuje trošak bez diranja najtežih delova. 09

8. Završni projekat

Termin Na engleskom Značenje Modul
portfolio agent portfolio agent Agent napravljen da radi i posle kursa, kao javni dokaz veština: rešava stvaran problem, ima evaluaciju, ograničenja i dokumentaciju. 10
dosije projekta project brief Jedna strana pre koda: šta agent radi i za koga, podaci, mera uspeha, šta ne radi, rizici, arhitektura; mesto gde se obim zaustavlja dok je jeftin. 10
kontrolna tačka checkpoint Spisak tvrdnji koje moraju važiti pre prelaska na sledeći deo projekta; dogovor koji drži obim pod kontrolom. 10
isporuka deliverable Ono što projekat zaista predaje: javni repozitorijum sa agentom, skupom, dosijeom i README-om — ne osećaj da je „skoro gotovo". 10
minimalna održiva verzija minimum viable product (MVP) Najmanja verzija koja korisniku daje vrednost: jedna vrsta zadatka, jedan korisnik, jedan izvor podataka; širina dolazi proširenjima. 10
rubrika rubric Ocena po opisima, ne po osećaju: dimenzije i nivoi (0–3) koji određuju i koliko je urađeno i šta je sledeći korak. 10
prezentacija u tri rečenice elevator pitch Šta agent radi i za koga · kako (arhitektura imenom) · zašto mu verovati (evaluacija, logovi, kočnice) — po redu kojim će i drugi gledati. 10
